## 📝 说明 / Notes

### 用户文档在哪里？/ Where are user-facing documents?

用户和开发者文档位于项目根目录：

User and developer documentation is in the project root directory:

- **README.md** - 项目主页 / Project homepage
- **USER_GUIDE.md** - 完整用户手册 / Complete user guide
- **INSTALLATION.md** - 安装指南 / Installation guide
- **FAQ.md** - 常见问题 / Frequently asked questions
- **DEVELOPMENT.md** - 开发指南 / Development guide
- **CONTRIBUTING.md** - 贡献指南 / Contribution guide
- **CHANGELOG.md** - 版本变更历史 / Version changelog
- **ARCHITECTURE.md** - 架构设计 / Architecture design

### 为什么分离内部文档？/ Why separate internal documents?

1. **清晰的结构** / Clear structure
   - 避免根目录文档过多
   - 区分面向用户的文档和内部文档

2. **更好的维护** / Better maintenance
   - 内部文档可以更频繁地更新
   - 不会影响用户体验

3. **专业形象** / Professional image
   - 保持项目主页简洁
   - 符合开源项目最佳实践
